# Glossary / Речник

> Keep the table in alphabetical order. One term per row. / Пазете таблицата по азбучен ред. Един термин на ред.

| Term / Термин | Meaning / Значение |
|---|---|
| Artifact | Artifact is highly associated and related to specific methods or processes of development. Methods or processes can be project plans, business cases, or risk assessments.
| Container | A container is an isolated, stand-alone unit that encapsulates an application and all its dependencies. It runs consistently in any environment, independent of the host system.
| CI | Continuous integration: every change is built and tested automatically. / Всяка промяна се изгражда и тества автоматично. |
| Deployment | Putting a version of the service where users can reach it. / Поставяне на версия на услугата там, където потребителите я достигат. |
| Health check | An endpoint that says whether the service is alive. / Адрес, който казва дали услугата е жива. |
| Issue | A task, bug or idea tracked on GitHub. / Задача, бъг или идея, проследявани в GitHub. |
| Pipeline | At its core, a pipeline in programming refers to a series of connected processes or stages where the output of one stage serves as the input for the next. This concept allows for efficient data processing, improved performance, and streamlined workflows in various programming paradigms.
| Pull request | A proposal to merge one branch into another, with review. / Предложение един клон да се слее в друг, с ревю. |
| Rollback | A rollback is what you use to reverse a change and restore a system, database, or application to a previous safe state. It acts as your safety net when something goes wrong, letting you undo changes that introduced errors or instability. You rely on rollbacks anytime reliability matters.
| Tag | Tags can trigger specific actions or workflows. For instance, pushing a new tag can automatically trigger deployment processes, testing pipelines, or production rollouts.
| Version | A named state of the service, e.g. 0.2.0. / Именувано състояние на услугата, напр. 0.2.0. |
